# Self-exploration with boundaries

Use for: Uncertain interpretations or reflection becoming more intrusive than useful.

The user controls whether to explore a topic. More interpretation is not automatically better.

## Approach

1. Mark what is known, what is the user's association, and what is an analyst-supplied guess.
2. Ask a non-leading question only if it serves the user's request; permit no answer.
3. Stop when the interpretation adds no discriminating information or the user rejects the lens.
4. Separate reflective insight from practical needs such as rest, support, or addressing an actual conflict.

Do not run evocative exercises to recover alleged memories or intensify unusual experiences. A grounded description can be a better outcome than a deeper symbolic story.

For historical attribution, consult the [research index](research/README.md) and the relevant source before asserting that Jung made a particular claim.
