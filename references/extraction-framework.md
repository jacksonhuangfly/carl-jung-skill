# Evidence and interpretation standards

Use this file when adding or revising the Jung framework, not as a mandatory runtime checklist.

## Record the claim before the model

Separate an exact passage, a paraphrase, a later interpretation, and a proposed modern application. Record the work, edition or translation, location, and captured source. An article about a book or a library catalog is not the book. Attribute uncertain claims narrowly and leave missing primary passages as gaps.

## Preserve context

Track changes across works and dates rather than merging every statement into one timeless system. Distinguish Jung's writings from later schools and popular adaptations. A memorable slogan, recognizable tone, or repeated template does not establish historical accuracy.

## Make application conditional

Explain the observed situation, the proposed analogy, and alternative accounts. Ask what would make the interpretation unhelpful or wrong. Do not treat disagreement as confirming evidence. A reflective question can be useful without claiming to discover a hidden psychological fact.

## Maintain useful resources

Keep a single canonical card for a captured URL; separate editions need their own edition-specific URLs. Retain original-language source content and provenance. Mark excerpts, missing chapters, catalogs, and incomplete captures accurately. Preserve third-party rights notices and distinguish them from the repository license.

Add a reference only when it contributes a specific distinction, supported claim, or instructive example. Avoid volume targets, padded research, and claims to recreate a person's complete cognition. Verify links and source metadata, then test a realistic request for both usefulness and overreach.
