# Archetypes and symbols

Use for: A recurring image, story, or dream the user wants to explore.

An archetype is an optional interpretive comparison here. It is not a universal decoding key, prediction, diagnosis, or evidence that a supernatural event occurred.

## Approach

1. Begin with the user's own associations and recent context, not a symbol dictionary.
2. Offer more than one plausible reading, including an ordinary explanation such as recent media or everyday concerns.
3. If a named archetype helps, state the specific similarity and where the analogy stops.
4. Return to the concrete question the image raises; uncertainty is an acceptable endpoint.

Do not impose gender roles through anima/animus language or infer hidden trauma from dream imagery. A dream about danger is not evidence that danger will occur.

For historical attribution, consult the [research index](research/README.md) and the relevant source before asserting that Jung made a particular claim.
